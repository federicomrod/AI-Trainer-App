# Event knowledge: IRONMAN 70.3 (half-distance triathlon)

Editable reference the coach is given when a goal mentions a half
Ironman, 70.3 or a triathlon. Checked 2026-11-16. UNVERIFIED items must
be said as uncertain.

## Format

Swim 1.9 km, bike 90 km, run 21.1 km, in that order, one continuous
clock including transitions. Full Ironman (3.8 km / 180 km / 42.2 km)
is a different event with different training.

## Benchmarks

One race's age-group data (Tallinn 70.3), so course, wind and water
matter:

| | Average | Good | Excellent |
|---|---|---|---|
| Men | 6:30 | 5:17 | under 4:35 |
| Women | 6:40 | 5:53 | under 4:55 |

- Suggested milestones for first-timers: finish under 7:00, then
  under 6:00; under 5:00 is ambitious for an experienced age-grouper.
- Pro reference times: men 3:26:06, women 3:53:02.

## What it demands (coaching knowledge, not sourced)

- It is an aerobic event of roughly 4.5 to 7 hours for most age-groupers.
  Easy volume, a long ride and a long run build the base; a few
  race-pace blocks sharpen it.
- Swim technique often limits more than fitness; it needs frequency.
- Strength work shifts from building size to maintaining strength and
  protecting the athlete from injury as run and bike volume rise. Legs
  day the day before a key long run or ride is a conflict to avoid.
- Typical plans run 12 to 24 weeks with a taper of about 1 to 2 weeks.
